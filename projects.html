AR Art Visualization and Marketplace App

Flutter Dart Firebase Android AR
Live Academic + Personal

Overview

A mobile application that enables users to visualize artwork in their own space before purchase, while providing sellers with a complete set of tools to manage an online art business. Built for Android using Flutter and powered by Firebase services.

Technical Highlights

  • ✦ Implemented image-based AR visualization overlaying artwork onto a live camera feed for realistic previewing on real walls.
  • ✦ Built a role-based system supporting General Consumers, Art Sellers (Go Creator), and unauthenticated Guest Users with tailored permissions.
  • ✦ Integrated a complete marketplace with wishlist, cart management, and secure checkout via the PayHere payment gateway.
  • ✦ Developed a dedicated Art Seller workspace for inventory management, order tracking, and customer communication.
  • ✦ Utilized Firebase Authentication, Cloud Firestore, and Cloud Storage for a scalable, real-time backend architecture.

Study Planner & Productivity Web App

React Node.js PostgreSQL Docker REST API
Still Contributing Personal Project

Overview

A web-based study planner targeting university students — features task scheduling, Pomodoro timer, progress tracking, and calendar view. Built with a React SPA frontend and a RESTful Node.js API backed by PostgreSQL.

Technical Highlights

  • ✦ Designed a normalized PostgreSQL schema with 6 tables — users, tasks, sessions, tags, goals, and logs.
  • ✦ Implemented drag-and-drop task re-ordering using the HTML5 Drag API with optimistic UI updates.
  • ✦ Wrote 40+ unit and integration tests using Jest and Supertest, maintaining >80% code coverage.
